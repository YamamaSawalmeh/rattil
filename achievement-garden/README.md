# Rattil – Achievement Garden 🌱

A gamified UI prototype for Rattil (the parent folder of this repo): every surah a student memorizes "plants" a tree in their personal garden (shrubs for short surahs, palms for long ones).

Built with **React 19 + TypeScript + Vite + Tailwind CSS**, plus `motion` for animations and `lucide-react` for icons. Prototyped in Google AI Studio.

## Run locally

Prerequisite: Node.js

```bash
npm install
cp .env.example .env.local   # add GEMINI_API_KEY if needed
npm run dev                  # http://localhost:3000
```
